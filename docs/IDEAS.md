# Идеи

## Smoke-экран при запуске

При открытии приложения экран затянут дымом, видно только лого. Пользователь трясёт телефон — дым рассеивается и открывается приложение.

- Детекция тряски через `DeviceMotionEvent` (на iOS 13+ нужен `requestPermission()`)
- Эффект дыма: CSS-анимация (простой вариант) или SVG `feTurbulence` (реалистичнее)
- Фоллбэк: таймаут 3-5 сек или тап по экрану, на десктопе — сразу клик
- Показывать только раз за сессию (`sessionStorage`)
