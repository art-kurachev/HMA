# MVP Roadmap — следующие фичи

## 1. Автокомплит табаков в полке

Сейчас полка — свободный текст. Добавить базу популярных табаков (бренд + линейка + название) для автокомплита при вводе.

**Зачем:** снижает ошибки ввода, LLM получает точные названия, UX становится приятнее.

**Реализация:**
- JSON-файл с 300–500 позициями (топ-15 брендов: Darkside, Must Have, Tangiers, Element, Duft, BlackBurn, Bonche, Satyr, Daily Hookah, Chabacco, Sebero, Adalya, Fumari, Al Fakher и др.)
- Источники: парсинг hookah-market.ru / kalyan.bar / сайтов брендов
- Фронтенд: поисковый инпут с выпадающим списком при вводе
- В будущем: crowdsource — пользователи добавляют табаки, админ подтверждает

---

## 2. "Ещё похожие" после положительного фидбека

После того как пользователь поставил 👍, предложить кнопку "Сделать похожий микс".

**Зачем:** повышает retention, пользователь чувствует персонализацию.

**Реализация:**
- Кнопка на экране фидбека после 👍
- Отправить те же параметры + информацию о предыдущем миксе в LLM с просьбой сделать вариацию
- Тратит 1 генерацию

---

## 3. Реферальная система

"Пригласи друга — получи +3 генерации."

**Зачем:** бесплатный growth-канал, мощный рычаг для привлечения.

**Реализация:**
- Deep link через `startParam` в Telegram Mini App (`t.me/bot?startapp=ref_<telegram_id>`)
- При первом входе по ссылке — бонус обоим (приглашённому и пригласившему)
- Таблица `referrals` в БД: кто кого пригласил, когда, начислен ли бонус
- Защита от абьюза: бонус только при первом входе нового пользователя

---

## 4. Онбординг-попап

При первом запуске — модалка с объяснением возможностей и сути приложения.

**Зачем:** новый пользователь сразу понимает что делать, не теряется.

**Реализация:**
- Модальное окно поверх WelcomeScreen
- 2–3 блока: что умеет приложение, два пути (быстрый/детальный), полка табаков, генерации
- Флаг `onboarding_seen` в localStorage, больше не показываем
- Кнопка "Понятно" закрывает

## Отложено / Отклонено

| Идея | Причина отказа |
|------|---------------|
| История миксов / Избранное | Уменьшит количество генераций и, как следствие, покупок |
| Поделиться миксом | У друзей вряд ли совпадут табаки — низкая ценность |
| Социальные фичи (лента, лайки) | Слишком рано, нет аудитории |
| Геймификация (достижения, уровни) | Отвлекает от основной ценности |
| Реалтайм-чат с ИИ | Другой UX, высокая стоимость токенов |
| Маркетплейс табаков | Совсем другой продукт |
