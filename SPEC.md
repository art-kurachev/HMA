# Спецификация продукта

## Цель

Telegram Mini App — ИИ-ассистент для подбора кальянных миксов. Пользователь вводит параметры сетапа и доступные табаки, получает 3 микса с инструкцией по забивке.

## Целевая аудитория

Кальянщики (любители и профессионалы), которые хотят попробовать новые сочетания табаков.

## Пользовательский сценарий

1. Открыть Mini App из Telegram-бота
2. Выбрать направление (тип сеанса)
3. Указать параметры: чаша, жар, крепость, вкусовые профили, доступные табаки
4. Получить 3 микса (название, табаки, описание вкуса)
5. Выбрать микс → получить инструкцию (табаки с %, забивка, прогрев, курение)
6. Запустить таймер прогрева
7. При проблемах — открыть sheet с советами
8. Оценить результат (фидбек)

## Критерии готовности MVP

1. Mini App открывается из Telegram и проходит полный флоу
2. Mock-провайдер возвращает 3 микса и инструкцию
3. Таймер работает корректно (старт, пауза, сброс)
4. Фидбек сохраняется в БД
5. UI соответствует Figma-макетам
6. Backend доступен по HTTPS
7. Нет критических ошибок в консоли

## JSON-контракты

### POST /v1/mixes/suggest → SuggestResponse

```json
{
  "mixes": [
    {
      "id": "mix_1",
      "title": "Название микса",
      "tobaccos": ["Табак 1", "Табак 2"],
      "flavor": "Краткое описание вкуса 4-6 слов",
      "mix_db_id": 1
    }
  ],
  "clarify": []
}
```

### POST /v1/mixes/{id}/instruction → InstructionResponse

```json
{
  "tobaccos": [
    { "name": "Табак", "percent": 50 }
  ],
  "packing": ["шаг 1", "шаг 2"],
  "warmup": ["старт: N углей", "прогрев: X минут"],
  "warmup_seconds": 360,
  "smoking": ["как курить"],
  "if_not_opened": ["что делать"]
}
```
