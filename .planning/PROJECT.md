# Hookah Mix Assistant (HMA)

## What This Is

Telegram Mini App для кальянщиков: AI подбирает табачные миксы, генерирует пошаговые инструкции по забивке и прогреву, помогает выбрать что купить в магазине. Работает через GigaChat, распространяется через Telegram Stars.

## Core Value

Пользователь за 30 секунд получает готовый микс и инструкцию — не нужно думать, просто открыл и закурил.

## Requirements

### Validated

- ✓ Быстрый подбор 3 миксов по цели вечера (movie / relax / surprise) — existing
- ✓ Подробный подбор 3 миксов по параметрам сетапа (чаша, угли, крепость, табаки) — existing
- ✓ AI-инструкция по выбранному миксу (забивка, прогрев, курение, troubleshooting) — existing
- ✓ Таймер прогрева с уведомлением через Telegram — existing
- ✓ Полка сохранённых миксов (localStorage) — existing
- ✓ Оценка миксов (👍/👎) с сохранением в БД — existing
- ✓ Оплата через Telegram Stars (платные генерации) — existing
- ✓ Система квот: 3 welcome + 1/неделю + пятничный бонус + paid — existing
- ✓ Admin панель для управления настройками LLM — existing

### Active

- [ ] Хранение списка покупок на сервере по Telegram ID

### Out of Scope

- Парсер фото табаков — будущая фича, требует отдельного ML-пайплайна
- Автокомплит табаков — деферировано, нет источника данных
- Похожие миксы / рекомендации — деферировано
- Реферальная программа — деферировано
- Полноценное приложение (не Telegram Mini App) — долгосрочная цель, не текущий milestone

## Context

- **Стек:** React + Vite (frontend), FastAPI + Python (backend), PostgreSQL (prod) / SQLite (dev)
- **LLM:** GigaChat (Сбер) — единственный провайдер, fallback — MockProvider
- **Auth:** Telegram initData в заголовке `X-Telegram-Init-Data`
- **Хранилище:** существующий `shelfStorage.ts` в localStorage — для полки. Список покупок идёт на сервер (надёжнее)
- **Паттерн генерации:** quick-suggest уже умеет делать 3 микса без параметров — список покупок расширяет этот паттерн до 10
- **Квота:** генерация 10 миксов = 1 запрос квоты (как обычный suggest)
- **Промпты:** все в `backend/app/core/prompt_builder.py`, строгие правила орфографии и запретов

## Constraints

- **Tech stack**: FastAPI + React, менять не планируем — всё уже работает
- **LLM**: только GigaChat — нет других ключей, но архитектура провайдеров позволяет добавить
- **Telegram**: приложение работает только внутри Telegram WebApp, FALLBACK_ID блокирует prod-запросы извне
- **Квота**: список покупок расходует квоту — нельзя делать бесплатным (монетизация)
