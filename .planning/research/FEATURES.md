# Features Research — Shopping List

## Table Stakes (пользователь ожидает)

### Генерация списка
- ✅ Генерация разнообразных миксов (не повторяются стили/профили)
- ✅ Показывает название + состав каждого микса
- ✅ Отображает процентные пропорции табаков

### Просмотр в магазине
- ✅ Свёрнутый список уникальных табаков (не 10 × N табаков, а дедублированный список)
- ✅ Чекбоксы рядом с каждым табаком — отмечать купленные
- ✅ Визуальное разделение купленных / не купленных
- ✅ Список сохраняется при выходе из приложения

### Управление
- ✅ Кнопка перегенерации (с предупреждением о расходе квоты)
- ✅ Очистка отметок (начать заново)

## Differentiators (конкурентное преимущество)

- 🔶 Группировка табаков по бренду (удобнее искать на полке)
- 🔶 Показывает в каких миксах используется каждый табак ("Darkside Hola — в 3 миксах")
- 🔶 Сортировка по количеству использования (купить сначала то, что нужно для большинства миксов)
- 🔶 Шаринг списка — отправить другу

## Anti-features (намеренно не строим)

- ❌ Несколько списков — усложняет UX, один список = одна цель
- ❌ Редактирование миксов вручную — слишком сложно для v1
- ❌ Ценники / магазины — нет источника данных
- ❌ История списков — избыточно для v1

## Рекомендация для v1

**Минимальный но полезный:**
1. Свёрнутый список уникальных табаков с чекбоксами
2. Раскрывающиеся карточки миксов (по тапу — показать состав)
3. Кнопка перегенерации с подтверждением
4. Сортировка по популярности (табаки встречающиеся в большинстве миксов — сверху)

Differentiator из коробки: сортировка по частоте использования — уникальная фича, добавляет реальную ценность (знаешь что купить в первую очередь).
