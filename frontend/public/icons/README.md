# Иконки приветственного экрана (Iprit)

Положи сюда SVG с **такими именами** (как в макете):

| Файл | Где используется |
|------|-------------------|
| `Union.svg` | Логотип Iprit (слева сверху) |
| `Database.svg` | Кнопка «Моя полка» (Linear Essentional UI Database) |
| `ShareCircle.svg` | Кнопка «Просто и быстро» (Linear Essentional UI Share Circle) |
| `RoundGraph.svg` | Кнопка «Сетап» (Round Graph) |

В SVG можно задать `fill="currentColor"`, тогда цвет иконки будет совпадать с цветом текста кнопки.

После добавления файлов перезагрузи страницу.
